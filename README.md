# 🚀 Shadowrocket Config & Auto-Updating Rules

Этот проект появился благодаря работе Михаила — https://github.com/misha-tgshv.

За основу был взят его конфиг, который затем был значительно переработан и адаптирован под мои сценарии использования. Сейчас репозиторий развивается независимо и содержит собственные наборы правил и конфигурацию.

---

# 📱 Что это?

Набор автоматически обновляемых правил для **Shadowrocket (iOS)**.

Конфигурация использует `RULE-SET`, благодаря чему большинство изменений применяется автоматически без необходимости редактировать конфиг на устройстве.

Основная цель проекта:

* максимально стабильная работа VPN в режиме **Always On**;
* минимальное количество ручных правил;
* автоматическое обновление всех списков;
* корректная работа российских, китайских и системных сервисов.

---

# 📥 Установка

## VPN-by-default (рекомендуется)

Основной и единственный актуальный конфиг.

**Логика работы:**

* 🇷🇺 Российские сервисы → **DIRECT**
* 🇨🇳 Китайские сервисы → **DIRECT**
* 🍎 Большинство сервисов Apple → **DIRECT**
* ▶️ YouTube → **PROXY**
* 🍎 Apple Media (App Store, Apple TV, Apple Music и др.) → **PROXY**
* 🚫 Реклама и трекеры → **REJECT**
* 🌍 Всё остальное → **PROXY**

Идеально подходит тем, кто хочет постоянно держать VPN включённым и не думать о маршрутизации.

### Установка

```
https://cdn.jsdelivr.net/gh/MyNicknme/shadowrocket-rules@main/config/VPN-by-default.conf
```

# ⚠️ Старые конфигурации

Ранее в репозитории присутствовали дополнительные варианты конфигурации (например **Only Blocked**).

На данный момент они **больше не поддерживаются и не обновляются**.

Разработка ведётся только для:

**VPN-by-default.conf**

# 📂 Структура правил

Все правила разделены на независимые списки.

## DIRECT

* Apple System
* Apple IP
* Russia
* Russian Services
* China
* Google Direct
* Duolingo
* 2GIS
* LAN

## PROXY

* YouTube
* Apple Media Services

## REJECT

* Ads & Trackers

Благодаря разделению можно легко добавлять собственные правила без изменения основного конфига.

# 🔄 Обновление

Все файлы из папки `rules/` обновляются автоматически через `RULE-SET`.

Чтобы обновить правила вручную:

```
Config → выбрать конфиг → Update
```

или

```
Force Update
```

---

# ⚠️ Важно

Если изменяется только содержимое `.list` файлов, Shadowrocket обновит их автоматически.

Если изменяется сама структура конфига (например добавлены новые `RULE-SET` или изменён порядок правил), рекомендуется заново установить конфигурацию по ссылке.
